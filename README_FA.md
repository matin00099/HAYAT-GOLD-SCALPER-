# HAYAT GOLD SCALPER — نسخه اولیه اندروید

این پوشه سورس پروژه Android Studio است؛ APK آماده و امضاشده نیست.

## وضعیت فعلی
- رابط فارسی و راست‌چین‌سازی اولیه با تم مشکی/طلایی
- صفحه داشبورد و کارت‌های موجودی، اکوییتی و سود/زیان
- بخش تنظیمات ریسک
- دکمه‌های شروع، توقف و توقف اضطراری در حالت نمایشی/غیرفعال
- هیچ اتصال زنده‌ای به MT5 یا VPS وجود ندارد و اعداد حساب عمداً با «—» نمایش داده می‌شوند.

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## کارهای ضروری پیش از استفاده واقعی
1. ساخت سرویس امن روی Windows VPS.
2. تعریف API احراز هویت‌شده برای وضعیت حساب، معاملات، تاریخچه و فرمان‌ها.
3. اتصال سرویس به MT5/EA و طراحی پروتکل امن فرمان‌ها.
4. ذخیره امن توکن دسترسی در Android Keystore؛ عدم ذخیره رمز اصلی حساب معاملاتی.
5. پیاده‌سازی و تست واقعی توقف اضطراری، کنترل خطا، قطع اینترنت و بازیابی اتصال.
6. تست روی حساب دمو؛ تا پایان تست، استفاده روی حساب واقعی ممنوع.

## محدودیت مهم
تنظیمات ریسک داخل این نسخه فقط در رابط کاربری تغییر می‌کنند و هنوز به EA ارسال نمی‌شوند. تنظیمات محافظتی EA باید بدون تأیید صریح تغییر نکنند:
- ریسک هر معامله: 0.25%
- حداکثر ضرر روزانه: 1.50%
- حداکثر یک معامله باز
- بدون مارتینگل


## ساخت APK فقط با گوشی (GitHub Actions)
1. در گوشی وارد https://github.com شوید و یک حساب بسازید/وارد شوید.
2. یک مخزن جدید (New repository) با نام `HAYAT-GOLD-SCALPER` و حالت Private بسازید.
3. فایل ZIP پروژه را از حالت فشرده خارج کنید و محتوای پوشه را در مخزن بارگذاری کنید؛ پوشه مخفی `.github` و فایل workflow باید هم بارگذاری شوند.
4. در مخزن، بخش Actions را باز کنید و workflow با نام `Build HAYAT Android APK` را اجرا کنید؛ یا پس از push خودکار اجرا می‌شود.
5. پس از پایان موفق، در اجرای workflow بخش Artifacts فایل `HAYAT-GOLD-SCALPER-debug-apk` را دانلود کنید.
6. ZIP مربوط به Artifact را باز کنید و `app-debug.apk` را نصب کنید.

توجه: این مسیر APK آزمایشی (debug) تولید می‌کند. برای انتشار عمومی، امضای release و بررسی امنیتی لازم است.
